# Box and Cox

Box and Cox 브랜드 소개 웹사이트. 정적 HTML/CSS/JS로 제작되었습니다.

## 구조

```
index.html      메인 페이지 (Hero, About, Products, Contact)
css/style.css   스타일 (미니멀/모던, 라이트·다크 모드 지원)
js/main.js      모바일 메뉴 토글, 스크롤 reveal 애니메이션
```

## 로컬에서 보기

별도 빌드 과정 없이 `index.html`을 브라우저로 열거나, 로컬 서버로 실행하세요.

```
python3 -m http.server 8080
```

## 콘텐츠 수정

현재 제품 소개(Product One/Two/Three)와 브랜드 설명은 플레이스홀더입니다.
`index.html`의 `#about`, `#products` 섹션 텍스트를 실제 브랜드 내용으로 교체하세요.
